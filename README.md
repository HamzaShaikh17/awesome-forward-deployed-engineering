# AI Deployment Engineering

A structured production-engineering curriculum for building, deploying, scaling, and operating AI products.

## Learning path

1. API & application engineering
2. Security & request protection
3. Performance & scalability
4. Async & distributed systems
5. Deployment & infrastructure
6. AI-specific production patterns

## Topics covered

- REST API design with HTTP semantics
- Async programming
- Dependency injection
- Clean architecture
- Middleware
- Error handling
- Logging
- Input validation
- Authentication & authorization
- Rate limiting
- Load balancing
- Redis caching
- Horizontal scaling
- Database indexing
- Event-driven systems
- Queues: Kafka / SQS
- Webhooks
- Microservices vs monolith
- CAP theorem
- EC2 vs serverless
- IAM
- S3 usage patterns
- Docker
- CI/CD
- Environment variables & secrets
- Nginx
- Domain & SSL
- Kubernetes basics

## How to use this repository

Each topic is intentionally organized as a standalone lesson. Read the concept first, then implement the examples, then complete the production checklist.

The target is not memorization. The target is being able to design and operate a production AI service and explain the trade-offs behind each decision.
